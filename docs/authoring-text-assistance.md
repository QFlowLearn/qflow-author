# Live question composer

In the assessment builder, choose **Type or paste a question** at any insertion point. Type freely
or use your operating system's dictation in the same field. For example:

> MC 4 options, Who was the second president, Thomas Jefferson, George Washington, you do the rest,
> randomize.

The preview shows the supplied stem and alternatives, the requested number of rows, and the
randomization setting. When you explicitly request completion, QFlow adds missing options and
proposes an answer. Suggestions are labeled and editable, and can be saved immediately. The original
text remains visible and editable. Single choice, multiple response, and short answer (text entry)
are supported. Lettered/numbered alternatives and a final `Answer:` block also support local
deterministic preparation. Continuation lines after `Answer:` stay in the answer.

The source field stays mounted during recognition. After an 800 ms pause, an untouched draft can be
prepared automatically. The type selector shows the current question type; choosing a type overrides
inference. Editing prepared fields pauses automatic replacement. **Replace draft from text**, **Undo
preparation**, and **Restore prepared draft** retain the displaced draft and suggestions. **Use the
editor below** dismisses pending source preparation. Saving is blocked while changed source is
waiting. Obsolete responses cannot apply. Changing only randomization reuses the most recent
completion for that question, including an in-progress request. A randomization-only change
preserves completed options, their authoring order, and the answer key; content changes request a
fresh completion. A different question, manual editing, or leaving the editor cancels the obsolete
request; failed requests can be explicitly retried.

The current builder session remembers only the type and answer-row count of its last five
successfully created supported questions. Reloading ends that session. Persisted presentation
preferences continue independently. Answers, scoring, and wording are never copied from previous
questions. Explicit randomization instructions override presentation defaults and update the
settings rail as well as the canonical draft.

## Interpretation and completion

Clef makes bounded decisions: question type, option count, randomization, completion intent, and the
role of each source span. Wording is copied from source spans, never generated by Clef. At most 24
spans are interpreted per request. Ambiguous spans or confidence below 0.8 yield uncertainty;
explicitly selected types do not depend on the type classifier's confidence. This threshold is a
policy, not a calibrated accuracy claim. Unsupported instructions may need manual editing. Straight
and curly quotes keep comma-containing phrases together; thousands separators stay with their
numbers. Adjacent stem fragments retain their original punctuation and line breaks.

The separate completion endpoint uses the configured Cloudflare generation model only after an
explicit completion request. It accepts exactly the missing options and an answer naming actual
options. Supplied wording, options, and explicit keys cannot be rewritten. Missing/duplicate
options, invented option references, and invalid keys are rejected. The preview is prepared before
generation finishes; generation latency is additional to recognition latency. Autocomplete requests
explicitly disable extended reasoning and request JSON output from the configured model (currently
Kimi K2.6). This favors a responsive drafting loop.

## Cloudflare configuration

Interpretation requires `AI`, `QFLOW_AUTHORING_GATEWAY_ID`, `QFLOW_AUTHORING_MODEL_VERSION`, and
`QFLOW_AUTHORING_RATE_LIMIT`, as shown in `cloudflare.config.ts`. Configure gateway spend controls
and permit `@cf/cloudflare/clef`. Set `QFLOW_AUTHORING_MODEL_VERSION=clef` to select the full model.
Completion additionally requires `QFLOW_AI_PROVIDER=cloudflare` and the explicit
`QFLOW_CLOUDFLARE_AI_MODEL`, shared with existing question generation. Missing configuration
produces a visible failure. Explicit syntax parsing remains available in local development without
an AI binding.

Both endpoints require assessment access and content-write permission. Requests bound source text to
12,000 characters, history to five structures, and streamed JSON to 52,000 bytes. Interpretation
waits up to ten seconds; completion waits up to 45 seconds. Both use the shared authoring rate limit
of twenty requests per author/workspace per minute. These limits are abuse protection, not an exact
global billing cap. Automatic interpretation makes at most ten calls per open question; further
attempts require explicit preparation. Providers are not automatically retried. Cancellation stops
waiting and discards stale results; it does not guarantee cancellation of billed remote inference.

Clef gateway requests use `collectLog: false` and `skipCache: true`. Raw question text and provider
exception messages must never enter application logs.

## Verification

Run `tests/question_text_test.ts`, `tests/question_assistance_test.ts`,
`tests/question_composition_test.ts`, `tests/question_completion_session_test.ts`, and the opt-in
`tests/question_text_browser_test.ts` against a disposable migrated database. Browser coverage
includes dictation/IME input, focus, stale replies, Undo, saving completed suggestions, settings,
mobile layout, and persisted completed questions. Controlled HTTP responses exercise races
separately from a real Cloudflare binding probe.

A timed human comparison remains a separate product evaluation; technical checks do not establish
time savings.
